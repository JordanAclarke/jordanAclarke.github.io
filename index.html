How I build agents

Five principles, with evidence

  1. The model decides; code executes. The LLM picks the action and fills the slots; deterministic code performs the transaction. Evidence: the agent’s tools are TypeScript services that call REST APIs, so code, not the model, performs every transaction.
  2. A human approves before anything changes. Evidence: led human-in-the-loop approval across three tools and two codebases.
  3. “Done” means saved. The assistant confirms only what the system committed. Evidence: fixed false “success” replies so confirmations match what the system saved.
  4. Evals run before merge. Descriptions are API: schemas, fixtures, and tool descriptions change together. Evidence: eval suites and tool-description checks run before every merge.
  5. Fix problems in the layer that owns them. Evidence: put improved error wording where agents actually read it while keeping public API text stable, and built an eligibility API instead of reusing UI logic.

AI agent project

Selected work from my role at Workday, described at a high level.

Flagship project

A production AI agent for transactional workflows

Users make requests in plain language. The agent determines what is possible, requests approval, and confirms only what the system has persisted.

Challenge
An incorrect response in chat is an incorrect business transaction. Customers configure their systems differently, and what the UI displays can differ from what the agent must send.
Approach
TypeScript tools and agent definitions that adapt one agent to each customer’s configuration; an eligibility-aware API that limits the agent to valid actions; edit and cancel logic scoped to exactly what was requested; and a shared approval step before every change.
Reliability
Confirmations reflect the committed state of the system, and evals and tool descriptions are verified before every merge.
Outcome
Users are offered only valid actions, nothing is confirmed until the system has persisted it, and request, edit, and cancel share a single approval experience.
